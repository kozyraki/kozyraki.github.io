# Christos Kozyrakis Homepage

Source for the personal academic homepage at https://kozyraki.github.io/.

The site is based on the al-folio Jekyll theme and is intentionally kept as a small single-page site. Publications, projects, and current group members are listed on the MAST research group site.

## Local preview

```sh
bundle install
bundle exec jekyll serve
```

## Build

```sh
bundle exec jekyll build
```
